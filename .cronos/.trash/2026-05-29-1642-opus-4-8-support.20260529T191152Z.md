# Brief

Add first-class support for the newly released `claude-opus-4-8` model (released 2026-05-28, SDK v0.100.0) to Cronos.

## Background

- Model ID: `claude-opus-4-8`
- The installed CLI (2.1.145, built May 20) predates Opus 4.8. The latest CLI (2.1.156) resolves the `opus` alias to 4.8. The Dockerfile already uses an unpinned `npm install -g @anthropic-ai/claude-code`, so a rebuild will fetch 2.1.156 automatically.
- "Workflows" released alongside Opus 4.8 refers to the Anthropic Managed Agents API (`beta/agents`, `managed-agents-2026-04-01`) — a server-side feature Cronos does not currently use.

## Child tasks

1. Update agent definition files to `claude-opus-4-8`
2. Add `claude-opus-4-8` as an explicit selectable model option in backend + frontend
