Task worktree edits via `Edit` tool go to the file in the **task worktree's path** if you use the absolute path within `.cronos/workspaces/<task-id>/`. If you accidentally edit the file via the main space path (`/data/spaces/cronos-development/backend/...`), you must `cp` it into the task worktree before committing.
