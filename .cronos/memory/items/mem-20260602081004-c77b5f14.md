Added `AiToolDetail` model to `backend/app/models.py` and `GET /api/spaces/{space_id}/tool-content` endpoint to `backend/app/api/tools.py`. Endpoint accepts `path` + `scope` query params, validates path is under `{space_dir}/.claude/` (space) or `~/.claude/` (global) using `Path.is_relative_to()`, returns HTTP 400 on traversal / 404 on missing, infers category from resolved path segments, returns full file content.
