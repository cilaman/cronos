asyncio done callbacks fire via `call_soon` AFTER the task completes — they run in the NEXT event loop iteration. Testing `_log_mirror_error` requires `await asyncio.sleep(0)` twice: first to run the task, second to run the scheduled callbacks. Single sleep is insufficient. Also: `patch("app.api.features.log")` does NOT intercept the real logger used by the callback — use a custom `logging.Handler` on `logging.getLogger("app.api.features")` instead.
