Buttons inside `FormField` (which wraps children in `<label>`) get composite accessible names: the FIRST button in a label gets name "[label-span-text] [other-buttons-text]" (e.g. "Feature" button → "Type Fix"). Use `screen.getAllByRole("button").find(b => b.textContent?.trim() === "Feature")` or `getByText("Feature")` for first-in-label buttons; subsequent buttons in the same label get their own text as the accessible name. CSS `text-transform: uppercase` does NOT affect ARIA accessible names — use "New Feature" not "NEW FEATURE" in `getByRole("heading", { name: ... })`.
