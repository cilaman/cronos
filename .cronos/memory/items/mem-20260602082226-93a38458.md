`SpaceToolsPage.tsx` now uses `useSearchParams` (React Router) as the sole source of truth for the open tool panel. `selectedTool` is derived via `useMemo` from URL params + loaded tools; `handleToolClick` calls `setSearchParams` preserving other params; `handleClose` deletes only the three keys (`tool`, `category`, `scope`). No `useState` needed for the panel state.
