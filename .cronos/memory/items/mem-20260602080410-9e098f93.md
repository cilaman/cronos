When creating feature goals (new UI, new API endpoint, significant refactor), use CC-v1 pipeline structure: one shared scout task at goal level + one sub-goal per feature slice, each with analyst→architect→impl→test→review→doc phases wired via depends_on. Never create a separate Tests sub-goal — the test phase inside each sub-goal covers it. Updated create-goal skill to encode this pattern.
