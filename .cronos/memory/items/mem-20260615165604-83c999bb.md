In goal task worktrees, `git -C SPACE_DIR commit` lands on `main` (not the feature branch) when the feature branch is checked out in a different task's worktree. Fix: cherry-pick the errant main commit into the feature-branch worktree with `git -C FEATURE_WT cherry-pick HASH`, then reset local main via `git -C SPACE_DIR reset --hard origin/main`.
