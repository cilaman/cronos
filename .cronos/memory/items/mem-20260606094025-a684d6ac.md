Features page 404 root cause was a frontend/backend route mismatch in `frontend/src/api.ts`. Backend `features_router` (backend/app/api/features.py) is mounted at `/api/features`: `GET /api/features?space_id=`, `PATCH /api/features/{id}/feature-state` with body `{feature_state}`, `POST /api/features` with body `{space_id,title,type,brief}`. The frontend was calling `/api/spaces/{id}/features` and `/api/tasks/{id}/feature-state`. Fixed all three `api.ts` functions (`features`, `transitionFeatureState`, `createFeature`); hooks/components unchanged. 24 feature tests + build pass.
