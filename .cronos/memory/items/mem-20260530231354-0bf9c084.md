For goal feature branches checked out in another worktree (`fatal: 'feature/...' is already used by worktree`), don't try to switch — copy files to that worktree's path and commit via `git -C <feature-worktree>`. Then push with the `CRONOS_GIT_TOKEN` auth header dance.
