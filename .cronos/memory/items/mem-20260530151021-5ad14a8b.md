First task of a Cronos goal → run `goal-branch-setup` to create `feature/<goal_slug>` from `origin/main` and switch the worktree off `cronos/<task-id>`. Slug derivation: strip `YYYY-MM-DD-HHMM-` prefix from the goal ID. Then `goal-task-commit` stages source files only (avoid committing `backend/.coverage` artifact), commits with the task title as subject, and pushes via `CRONOS_GIT_TOKEN` HTTPS auth.
