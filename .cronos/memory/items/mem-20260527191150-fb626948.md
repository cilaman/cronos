Old code scanned only the last 10 lines for STATUS: markers. Agents with 10+ trailing lines after STATUS: DONE (MEMORY blocks, summaries) had the marker buried — parse_status() returned None → task went WAITING. Fix: full reverse scan. Regression tests: test_parse_status_buried_by_many_trailing_lines, test_parse_status_memory_block_before_status.
