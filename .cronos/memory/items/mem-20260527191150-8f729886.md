title: Trace exit_reason is the primary diagnostic for unexpected task states
ttl_until: '2029-08-19T15:09:02Z'
---

Trace files at .cronos/traces/<task-id>/000N.json. Key field: exit_reason — DONE (normal), NO_STATUS (STATUS: marker not found → task goes WAITING), WAIT (agent requested wait). If tasks end up in WAITING unexpectedly, check exit_reason in trace first.
