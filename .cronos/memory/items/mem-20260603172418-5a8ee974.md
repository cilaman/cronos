pytest's global `addopts = "--cov=app --cov-report=term-missing --cov-fail-under=60"` in `backend/pyproject.toml` caused all per-iteration validation_commands to fail with exit 1 even when all tests passed (coverage gate fires on single-file runs too). Fixed by removing `--cov-fail-under=60` from addopts; the coverage floor still applies via explicit flag when running the full suite with CI.
