When adding `onError`/`onSuccess` callbacks to an existing `mutate()` call that tests mock as a bare `vi.fn()`, existing `toHaveBeenCalledWith(singleArg)` assertions fail because `mutate` now receives a second argument. Update them to `toHaveBeenCalledWith(singleArg, expect.objectContaining({onSuccess: ..., onError: ...}))`.
