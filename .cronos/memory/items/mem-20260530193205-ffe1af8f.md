`git commit <pathspec>` (with `-m <msg>` BEFORE the `--`, like `git commit -m "..." -- <path>`) commits ONLY changes in that path, leaving an unrelated dirty index untouched. Useful when committing into a worktree someone else left mid-edit. Note: the file must already be tracked (run `git add <path>` first).
