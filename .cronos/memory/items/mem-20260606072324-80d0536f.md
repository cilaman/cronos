Auto-repair for missing sibling deps in `_run_goal` implemented in `backend/app/worker.py`. When `transition(child_id, ACTIVE)` raises `InvalidTransition("Cannot start task: unmet dependencies: X")` and X is a non-sibling (grandchild of goal), the repair walks up X's parent chain to find the sibling ancestor, calls `set_depends_on` to add it, re-runs `_topo_children`, and restarts the for-loop. Capped at 1 attempt per invocation via `_repaired` flag. 3 new tests in `tests/test_worker.py` cover repair-fires, no-repair, and unresolvable-dep cases.
