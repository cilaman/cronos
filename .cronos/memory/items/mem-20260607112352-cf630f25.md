When goal-task-commit uses `git -C "$SPACE_DIR"`, it runs in the main worktree, not the workspace worktree. If the feature branch is checked out in the workspace worktree, the commit lands on the wrong branch. Fix: use `git --git-dir="$WORKDIR/.git/worktrees/$TASK_ID" --work-tree="$SPACE_DIR"` to operate on the workspace worktree's index and HEAD.
