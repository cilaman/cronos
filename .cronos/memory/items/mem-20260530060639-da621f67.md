When a goal-task-commit finds the feature branch already checked out in the main worktree (git error: "already used by worktree"), copy changed files from the workspace to the main worktree with Python `shutil.copy2`, then run `git -C $SPACE_DIR add/commit/push` from the main worktree path instead of `git` in the current directory.
