When testing the pipeline with the in-repo goldens, the review/test/doc fixtures use bare `slug: fixture-test` (not the fan-out `--attempt1`) because the regression harness exercises them under the bare slug. Substring replacement isn't enough — need a YAML-aware rewrite (`re.sub(r"(?m)^slug:\s*\S+\s*$", ...)`) or the verifier's R6 rule fires on slug mismatch.
