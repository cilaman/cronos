New file `backend/tests/test_worker_sibling_dep_repair.py` adds 3 focused tests for the auto-repair of non-sibling deps in `_run_goal`. Key insight: the dependent subgoal's ID must sort BEFORE the prereq's ID (via `_topo_children`'s `(manual_order, cid)` key) so that the repair is actually triggered — if the prereq sorts first it runs first and the dep is already satisfied before the repair fires. Used "dep sg" (D < P) and "prereq sg" naming to control sort order.
