A sub-goal task whose immediate parent is itself a sub-goal must still resolve to `feature/<root-goal-slug>`. The reworked goal-branch-setup achieves this by walking the chain until `parent_id` is null; the resulting root goal id has its `YYYY-MM-DD-HHMM-` prefix stripped via `re.sub(r"^\d{4}-\d{2}-\d{2}-\d{4}-", "", root["id"])`. Planning/analysis-only goals are excluded from the skill by the explicit "Only run for development goals that deliver changes to the git repository" guard in the When-to-use section.
