`importlib.reload(app.worker)` inside a pytest test file poisons the module registry for all subsequent tests in the same session — even after restoring sys.modules["app.worker"]. Worker lifecycle tests timed out when run after the reload. Fix: replace the reload-based runtime import check with grep-only source inspection; the grep check is sufficient for the circular-import contract.
