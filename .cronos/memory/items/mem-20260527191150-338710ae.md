Race: child goes WAITING→ACTIVE → parent transitions WAITING→ACTIVE (no enqueue). Child finishes DONE → propagate_to_parent fires, parent already ACTIVE → old code did nothing → goal stuck ACTIVE forever. Fix: when parent_state == ACTIVE and child is DONE, still enqueue — unless worker.current() == goal_id (already running internally).
