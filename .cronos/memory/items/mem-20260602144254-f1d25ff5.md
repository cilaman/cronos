When using `git -C "$SPACE_DIR"` in the goal-task-commit skill, the command targets the **main worktree** (at `/data/spaces/cronos-development`), not the current task worktree. This caused a commit to land on `main` instead of the feature branch. The fix: commit using plain `git` (no `-C` flag) when already checked out to the feature branch in the task worktree — or verify `git branch --show-current` resolves to the feature branch before running `git -C`.
