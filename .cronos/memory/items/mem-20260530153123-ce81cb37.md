Pytest's default `python_functions = "test"` collects ANY function whose name starts with `test` (not just `test_`). Helper builders named like `test_header` or `tester_header` get scooped into the test suite and trigger `PytestReturnNotNoneWarning`. Prefix internal helpers with `_` or use a non-`test` verb.
