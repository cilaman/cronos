## Findings: Using Opus 4.8 in Cronos

### Model ID
The model ID is **`claude-opus-4-8`**, released 2026-05-28 in Anthropic SDK v0.100.0.

### "Workflows"
"Workflows" refers to the **Anthropic Managed Agents** API (`beta/agents`, beta header `managed-agents-2026-04-01`, added SDK v0.89.0). This is a server-side API for creating persistent agent configurations. Cronos uses the Claude Code CLI, not this API directly — so workflows integration would be a separate project. Using Opus 4.8 itself does **not** require Managed Agents.

### Root cause: CLI is outdated
The installed CLI is **2.1.145** (built May 20). Opus 4.8 was released May 28. Latest CLI is **2.1.156**. The `--model opus` alias in the current CLI still resolves to `claude-opus-4-7`.
