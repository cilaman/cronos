# Brief

Prepare a plan for updating the mechanism of task finalizing. Currently the problem is that the agent many times forgets to write STATUS: DONE at the end of the task, thus the task goes to Waiting despite the fact that it is done. I do not want to be dependent solely on the texting of the last message. I propose to create a skill for finalizing the task that will be mandatory at the end of every task execution. The skill will 
- move the task to another state based on the information from the executing agent
- handle git if necessary
- check trace 
- write to memory
+ propose further reasonable steps by yourself.

The skill should be self improving, so if user in next run points out some problem of the state transition, git or memory processing, the skill should improve iteself, create other skills or improve other skills based on the feedback.
