# Arc 5 — AI Tool Discovery, Adoption & Evolution: Execution Plan

## Context

Cronos-ready breakdown for **Arc 5** of the
[roadmap](let-s-discuss-key-features-async-hopcroft.md). Three
stacked, independently-shippable layers:

- **5a — Discovery (Goal A):** `/data/tool_sources.yml` lists
  external Git URLs; refresh shallow-clones each, walks
  `.claude/agents/*.md`, `.claude/skills/{*.md,*/SKILL.md}`,
  `.claude/commands/**/*.md`, `.claude/settings.json`; indexes into
  global SQLite `discovered_tools`.
- **5b — Adoption (Goal B):** vendor a discovered item into
  `{space}/.cronos/tools/<kind>/<name>/` with `manifest.yml`
  (`source_url, source_sha, base_sha, local_sha, evolved, ...`).
  Mount adopted dirs into agent runs. Upstream-advance + local
  edits ⇒ auto-create a 3-way merge task.
- **5c — Evolution (Goal C):** tag tool invocations with
  `adopted_tool_id`; weekly `evolve-tools` task opens a PR against
  the vendored file when success rates drop.

All three goals + children ship to **`feature/arc-5-tools`**. Each
child's last step is `test-architect` updating + running the suite
green; commit only after green.

**Locked decisions:**
- Discovery is **global** (`/data/tool_sources.yml`, clones at
  `/data/.cronos/discovery_sources/<slug>/`, SQLite index).
  Adoption is **per-space**.
- Adoption source-of-truth = `manifest.yml` + vendored file under
  `{space}/.cronos/tools/<kind>/<name>/`.
- Mount via extra `--add-dir` at
  [backend/app/agent.py:216](backend/app/agent.py#L216) + deep-merge
  adopted hooks/permissions into generated workspace
  `settings.json`.
- Evolve PR branch: `cronos/evolve/<kind>-<name>-<ts>`.

**Prerequisites:** Arc 1 (`type`, `parent_id`, `depends_on`). Arc 4
(autopilot PR flow) — Goal C reuses
`autopilot_pr.run_post_done_flow` / `git_ops` commit→rebase→push→PR
helpers.

### B1 — Adoption module + manifest

New `backend/app/tools/adoption.py`. Pydantic `AdoptionManifest`
fields as in the Brief above (YAML-round-tripped, atomic
tmpfile+os.replace).
- `async adopt(space_id, source_slug, kind, name) -> AdoptionManifest`
  — copies file (or skill dir verbatim) from discovery clone into
  `{space}/.cronos/tools/<kind>/<name>/`. Skill dirs preserve
  structure; flat files go to `<kind>/<name>.md`. Writes
  `manifest.yml`. Raises if already adopted (caller may unadopt
  then adopt).
- `async unadopt(space_id, kind, name)` — soft-delete to
  `{space}/.cronos/tools/.trash/<kind>/<name>-<ts>/` (matches
  [space_storage.py](backend/app/space_storage.py) trash pattern).
- `def recompute_local_sha(space_id, kind, name)` — sha256 of file
  (or canonicalised directory hash); updates manifest.
- Hook the existing `watch_spaces_dir` watcher in
  [main.py](backend/app/main.py) for `.cronos/tools/**` changes;
  call `recompute_local_sha` (throttled 1/s per file).

**Acceptance:** adopt copies file + manifest with correct hashes;
edit → `local_sha` flips within 2s; unadopt soft-deletes.

### B4 — Upstream-advance + 3-way merge task

Extend the A4 periodic refresh: after `walk_source` upserts new
`source_sha`s, scan every space's adopted manifests. For each entry
where `manifest.source_url == discovered.source_url AND
manifest.source_path == discovered.relative_path AND
manifest.source_sha != discovered.source_sha`:
- **Pristine** (`local_sha == base_sha`): overwrite vendored file,
  update `source_sha` + `base_sha`; log `tool.auto-upgraded`.
- **Locally edited:** create a Cronos task —
  `title: "Merge upstream changes to {kind}/{name}"`, `type: task`,
  `parent_id: null`, `agent_mode: plan`. Brief = 3-way diff (base
  vs upstream vs local) via `git diff --no-index`, includes
  `source_url`, target `source_sha`, and a Resolve protocol: "Edit
  the vendored file; mark task DONE — Cronos bumps `base_sha` to
  upstream and `local_sha` to the resolved file."
- On that task → DONE, post-DONE hook (alongside Arc 4 PR flow)
  calls `adoption.finalize_merge(space_id, kind, name)`:
  reads resolved file → sets `base_sha = upstream.source_sha`,
  `local_sha = sha256(resolved)`, `source_sha = upstream.source_sha`,
  `evolved = false`.
- **Guard:** if a non-DONE merge task already exists for
  `(space, kind, name)`, do NOT duplicate — re-render the diff into
  the existing task's brief.

**Acceptance:** upstream-advance + local-edit fixture → merge task
created with readable 3-way diff. DONE → manifest bumps correctly.
Pristine + advance → silent upgrade; manifest reflects new SHAs.

  `cronos/evolve/<kind>-<name>-<timestamp>`. PR title:
