# Brief

Investigate and fix tasks ending in WAITING unexpectedly.

## Root cause found
`asyncio.StreamReader` was hitting its default 64 KB line limit when reading claude's stdout. When an agent reads a large file (e.g. `storage.py` at ~32 KB), claude emits that as a single JSON line on stdout which JSON-encodes to 66–87 KB, exceeding the limit.

## Fix applied in `backend/app/agent.py`
1. Increased `limit` to 10 MB on `asyncio.create_subprocess_exec`.
2. Added process kill on read error to prevent `proc.wait()` deadlocking.
